# GitHub experiment records

This directory includes the original experiment hyperparameters, per-epoch losses and metrics, optimizer update evidence, model-selection decisions, aggregate OCR results, and numeric predictions without student answer texts. Model binaries, full OCR transcripts, student-text error-analysis tables, local environment snapshots, and browser diagnostic captures remain in the local complete project.

The report refers to that complete local experiment. The GitHub version deliberately records what was measured without redistributing the underlying raw datasets. Missing model checkpoints can be regenerated with the training commands or supplied separately by the project owner.
