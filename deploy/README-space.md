# 英文手写简答题智能评分

PyTorch + DistilBERT + TrOCR 中文课程演示。使用项目真实微调得到的两道题评分模型，满分均为 2 分。支持手写图片、多行识别、文本修改后重评、直接文本和批量评分。

文本测试 QWK：题目 3 为 0.6859，题目 4 为 0.6790。160 张具有参考转录的 OCR 留出图上，CER 10.05%、WER 33.92%；同批答案评分 QWK 由参考转录的 0.6697 降为 OCR 的 0.5522。识别错误会改变分数，请教师核对文字。

评分置信度仅为模型排序信号，不是预测正确率。复核阈值由验证集选择，测试自动评分子集精确一致率约 84%，不保证评分正确。系统仅供课程演示，不应直接替代教师给出正式成绩。

请使用匿名答案。上传内容不用于训练；临时上传文件由 Gradio 定期清理。原始数据集和学生转录不在此 Space 中再分发；该部署包含推理代码、真实最优评分权重和官方预训练 TrOCR。CPU 运行，首次加载和图片识别可能较慢。
